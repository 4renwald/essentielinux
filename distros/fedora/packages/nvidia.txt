# NVIDIA open kernel module driver for Turing-or-newer GPUs. The `*` entries
# are the driver itself; the rest is support userspace.
*kernel-devel-matched :: kernel headers for akmod builds
*akmod-nvidia-open :: NVIDIA open kernel module
*xorg-x11-drv-nvidia :: NVIDIA userspace driver
xorg-x11-drv-nvidia-libs.i686 :: 32-bit NVIDIA libraries for games
xorg-x11-drv-nvidia-cuda :: CUDA/NVENC libraries and nvidia-smi
xorg-x11-drv-nvidia-power :: suspend/resume systemd units
libva-nvidia-driver :: VA-API support for Firefox and Zen
mesa-demos :: OpenGL diagnostics
vulkan-tools :: Vulkan diagnostics
libva-utils :: VA-API diagnostics
